# ozon-analytics
Прогнозно-аналитическая система мониторинга и прогнозирования цены и объёма торгов акций МКПАО «Озон» (OZON) на Московской бирже

## Описание проекта

Система обеспечивает полный цикл работы с данными о торгах акциями МКПАО «Озон» (тикер OZON) на Московской бирже: от автоматизированного сбора данных из внешних источников до построения прогнозов и визуализации результатов в интерактивных дашбордах.

### Прогнозируемые показатели

1. **Цена закрытия** (Close) на следующий торговый день.
2. **Объём торгов** (Volume) на следующий торговый день.

## Архитектура системы

1. **Загрузка данных** — автоматизированный сбор данных из Мосбиржи и ЦБ РФ, инкрементальная загрузка, идемпотентность, устойчивость к сбоям, журнал загрузок.
2. **Обработка и хранение данных** — слоистая архитектура хранения, очистка, преобразование, объединение данных, контроль качества.
3. **Аналитический модуль** — предметный и операционный дашборды, аналитические витрины.
4. **Прогнозное ядро** — не менее двух моделей прогнозирования цены закрытия и объёма торгов, схема валидации, интерпретация метрик.
5. **Профильные компоненты** — контроль качества данных, управление метаданными, историзация изменений.

## Технологический стек

- **Оркестрация:** Airflow
- **Визуализация:** Superset
- **Конфигурация:** YAML / переменные окружения
- **Контейнеризация:** Docker / Docker Compose
